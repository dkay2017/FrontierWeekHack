# Care Approval IQ

_Proof beats paperwork._

A multi-agent system that helps hospitals prepare insurance authorisations and appeals: five reasoning agents on Microsoft Foundry prepare each case, a deterministic Microsoft Agent Framework workflow decides the route, and a person always approves the send.

Built for the Microsoft Agent-a-thon 2026 (Architect track).
